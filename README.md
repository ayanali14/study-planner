# StudyPlanner

StudyPlanner is a small web app that helps college students keep track of assignments, quizzes and lab work.

## Features
- Register and log in with email and password
- Add a task with a priority (Low, Medium, High)
- Mark a task as done (and reopen it)
- Delete a task

## Run it
Open `index.html` in a browser. There is nothing to install.

## Branches
- `main` - stable production code
- `develop` - ongoing development
- `release/v1.0.0` - pre-release testing
- `hotfix/login-bug` - urgent fixes after release
